📐 ทฤษฎี Inpaint Mask ในเชิง Image Processing

สิ่งที่เกิดขึ้นเมื่อส่ง Mask ไปให้โมเดล Latent Diffusion

1. สูตรการชดเชยมาตราส่วน (Scaling Math): X_nat = (X_client - rect.left) * (W_nat / rect.width)
Y_nat = (Y_client - rect.top) * (H_nat / rect.height)
ช่วยให้แม้ผู้ใช้จะซูมหน้าจอ หรือเปิดบนจอมือถือ พิกัดของหัวแปรงจะถูกแมปกลับไปยังตำแหน่งพิกเซลจริงของภาพได้แม่นยำ 100%
2. Binary Alpha Masking (ภาพขาว/ดำ): Output(x,y) = 255 (สีขาว: ให้ AI วาดใหม่) หรือ 0 (สีดำ: ล็อกภาพเดิม)
ภาพ Mask จะถูกส่งเป็น Base64 PNG ไปยัง Backend เพื่อส่งต่อให้ AI Server นำไปคูณแบบ Hadamard Product ใน Latent Space

🧠 คลังคำตอบสำเร็จรูป: สรุป 6 จุดตายที่อาจารย์ชอบจี้ถามฝั่ง Frontend

จำแนวทางคำตอบ 6 ข้อนี้ไว้ให้ขึ้นใจ ตอบได้อย่างมั่นใจ รับเกรด A ได้แน่นอนครับ

1. ทำไมถึงเลือกแปลง Mask บนเบราว์เซอร์แทนที่จะส่ง Vector ไปให้ Backend ทำ?

ตอบ: เพื่อลดความซับซ้อนในการคำนวณของ Backend และลดความหน่วง เบราว์เซอร์มี GPU Acceleration ผ่าน HTML5 Canvas 2D อยู่แล้ว การ Export ออกมาเป็น Binary PNG ขาว-ดำขนาดเท่ากับ Natural Resolution ตั้งแต่ต้นทาง ทำให้ Backend และ AI Server รับไปใช้งานได้ทันทีโดยไม่ต้องเสียเวลาทำ Rasterization ซ้ำ

2. การใช้ Adaptive Polling ดีกว่า WebSocket อย่างไรในโปรเจกต์นี้?

ตอบ: เนื่องจากงานสร้างภาพด้วย Diffusion ใช้เวลาประมวลผลเป็นงานๆ ไป (Discrete Job) ไม่ใช่การแชทแบบ Real-time Streaming การเปิด Persistent WebSocket Connection ค้างไว้จะกิน Socket File Descriptors บนเซิร์ฟเวอร์โดยไม่จำเป็น ขณะที่ Adaptive Polling ทำงานแบบ Stateless หากผู้ใช้ปิดหน้าเว็บหรือเน็ตหลุดจะไม่เกิด Connection Leak และยังสามารถใช้ HTTP Caching และ CDN เข้ามาช่วยลดภาระได้ด้วย

3. หน้าบ้านป้องกันปัญหา Memory Leak จากการแสดงรูปภาพขนาดใหญ่ซ้ำๆ อย่างไร?

ตอบ: เมื่อมีการสร้าง Object URL จากรูปภาพ Base64 หรือ Blob (ผ่าน URL.createObjectURL()) เราจะมีการเรียก URL.revokeObjectURL() เสมอใน Cleanup Function ของ useEffect เมื่อรูปนั้นถูกปิดหรือ Unmount ออกไป เพื่อคืนหน่วยความจำ V8 Heap Memory คืนให้เบราว์เซอร์ทันที

4. ถ้าระหว่าง Polling งานอยู่ แล้วผู้ใช้กด 'Cancel' กลไกทำงานอย่างไร?

ตอบ: เราใช้เทคนิค Optimistic UI โดยสั่งปรับ State ใน React Query ให้กลายเป็น cancelled ในทันทีเพื่อให้หน้าจอแสดงผลว่ายกเลิกแล้ว พร้อมส่งคำขอ POST /api/generations/{id}/cancel ไปยัง Backend เพื่อส่งสัญญาณ Hardware Interrupt ไปตัดงานบนการ์ดจอ RTX 3070 ต่อไป

5. ทำไมถึงต้องบังคับขนาดภาพพรีเซ็ตให้หารด้วย 8 ลงตัว (เช่น 512x680 แทน 512x685)?

ตอบ: เพราะโมเดล Stable Diffusion ทำงานบน Latent Space ผ่านโครงข่าย VAE ซึ่งมี Downsampling Factor เท่ากับ 8 เท่า (f=8) หากหน้าบ้านยอมให้ส่งเลข 685 เข้าไป มิติใน Latent Space จะกลายเป็น 85.625 ซึ่งไม่เป็นจำนวนเต็ม ทำให้เกิด Tensor Shape Mismatch ใน UNet Cross-Attention Layers ทันที การกรองตั้งแต่ Frontend จึงเป็นหัวใจของ Data Sanitization

6. ทำไมถึงเก็บ Token ใน LocalStorage/Memory Store แทนที่จะใช้ Cookie ปกติ?

ตอบ: เนื่องจากสถาปัตยกรรมระบบเป็นแบบ Decoupled API (Frontend อยู่พอร์ต 5173, Backend อยู่พอร์ต 8000) ซึ่งข้าม Origin กัน การใช้ Authorization Header แบบ Bearer Token ช่วยป้องกันการโจมตีประเภท CSRF (Cross-Site Request Forgery) ได้อย่างเด็ดขาดโดยไม่ต้องพึ่งพา CSRF Token เสริม

7. ทำไมฝ่าย Frontend ถึงต้องมีโมดูล families.js สำหรับตรวจจับตระกูลโมเดล และกรอง LoRA Dropdown แบบ Real-time?

ตอบ: เพื่อปฏิบัติตามหลักการ User Experience (UX) และการตรวจสอบข้อมูลล่วงหน้า (Pre-flight Validation) โดยสถาปัตยกรรม SD 1.5, Illustrious XL, และ Pony XL ใช้โครงข่าย Text Encoder และมิติที่ไม่เท่ากัน หากผู้ใช้จับคู่ LoRA ผิดตระกูล ภาพที่ได้จะพังเสียหาย โมดูล families.js จะอ่านค่า family จาก GET /api/models แล้วกรอง Dropdown ให้แสดงเฉพาะ LoRA ที่เข้ากันได้กับ Base Model ทันที พร้อมติดป้ายกำกับสี ช่วยป้องกันความผิดพลาดตั้งแต่ฝั่งผู้ใช้ก่อนส่งคำขอไปยังเซิร์ฟเวอร์ครับ

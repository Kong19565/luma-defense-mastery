💡 เคล็ดลับ 4 เสาหลักในการตอบคำถามอาจารย์วิชา Image Processing

1. ทฤษฎี Latent Space (ย่อขนาด f = 8 เท่า)

อธิบายว่า VAE ย่อภาพลง 8 เท่า (จาก 512×512 พิกเซล เหลือ 64×64 ใน Latent Space) ทำให้คำนวณเร็วขึ้นเกือบ 50 เท่า และขนาดภาพต้องหารด้วย 8 ลงตัวเสมอ

2. สูตร Color Dodge Blending

อธิบายสูตร: Dodge(I, B) = min(255, (I × 256) / (255 - B + 1)) และชี้แจงว่า cv2.divide ช่วยป้องกันการหารด้วยศูนย์ในระดับฮาร์ดแวร์ C++

3. WebP Image Compression

ชี้แจงว่าไฟล์ PNG มีขนาด 2-4MB การบีบอัดด้วย libwebp Method 6 (Quality 92) ช่วยลดขนาดไฟล์ลง ~80% เหลือ 200-400KB ลดภาระเน็ตเวิร์กมหาศาล

4. Asynchronous Webhook Architecture

ตอบให้ชัดเจนว่าทำไมไม่บล็อก HTTP Connection: เพราะการสร้างภาพใช้เวลานาน การใช้ FIFO Queue + Webhook เป็น Event-driven Pattern ที่ถูกต้อง
